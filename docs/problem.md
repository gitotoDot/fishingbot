# Problem Definition

## 1. 배경과 대상 사용자

FishingBot의 대상 사용자는 낚시 장난감을 이용해 고양이와 놀아주는 보호자이다.
낚시 장난감 놀이는 보호자가 장난감을 잡고 움직이는 조작을 지속해야 하므로,
보호자가 다른 일을 하는 동안에는 직접 놀이를 제공하기 어렵다.

보호자가 반복적인 조작을 줄이고 싶어 하는지, 자동 놀이가 실제로 도움이 되는지는
보호자 의견과 추후 실물 검증을 통해 확인할 가설이다.

## 2. 핵심 문제

보호자의 지속적인 수동 조작 없이 낚시 장난감 놀이를 제공하려면,
시작 시 장난감 보유 여부를 확인하고, 미보유라면 장난감을 찾아 집어 든 뒤,
고양이에게 접근하고 고양이에게서 멀어지는 동작을
하나의 흐름으로 수행할 수 있어야 한다.

이를 위해 카메라 인식, 이동부 제어, 로봇팔과 집게 제어를 연동해야 한다.
장난감과 고양이의 위치가 달라지고 이동 경로에 장애물이 있을 수 있으므로,
고정된 이동 순서만으로 전체 동작이 수행되는지 판단하기 어렵다.

## 3. 이번 단계에서 해결할 문제

차터의 전체 목표는 이동부와 로봇팔을 갖춘 시제품 개발이다.
이번 단계는 실제 하드웨어 제작 전 소프트웨어 개발과 MuJoCo 기반 시뮬레이션 검증까지로 한정한다.
MuJoCo를 필수 시뮬레이션 환경으로 사용하며, 이동부·로봇팔·집게와 장난감·고양이 대상·장애물·카메라를 구성해 전체 동작을 검증한다.
이번 단계에서 낚시 장난감은 낚싯줄을 생략한 색상 표식 막대로 대체하고, 고양이는 정지하거나 지정된 경로로 움직이는 모형으로 대체한다.
대체 대상도 카메라 영상으로 인식하며, 낚싯줄의 움직임·얽힘과 실제 고양이의 반응은 이번 검증 범위에 포함하지 않는다.

### 시작: 팔 인식·위치 보정 및 보유 상태 확인

꺼져 있을 때 전원 버튼을 한 번 누르면 켜지고 대기한다. 대기 중 같은 버튼을 한 번 누르면 바로 놀이, 두 번 연속 누르면 외출 모드를 시작한다.
외출 모드는 설계자가 정한 주기를 사용한다. 기본안은 모드 진입 시 첫 회를 시작하고 이후 2시간마다 한 회씩, 회당 10분간 진행하는 것이다.
두 모드 모두 한 회를 시작하면 카메라로 팔·집게 위치를 먼저 확인한다.
이동부를 정지한 상태에서 기존 파지를 유지하며 팔을 관측 자세로 보정한다.
팔이 보이지 않거나 보정할 수 없으면 임의로 움직이지 않고 정지한다.

전용 장난감을 이미 잡고 있으면 장난감 확보를 건너뛰고 고양이 탐색을 시작한다.
집게가 비어 있으면 최대 5분간 장난감을 찾는다. 찾으면 집어 든 뒤 고양이를 탐색하고, 5분 동안 찾지 못하면 정지하고 실패를 안내한 뒤 전원을 끈다.
가림 등으로 보유 여부를 알 수 없으면 미보유로 단정하지 않고 정지 상태에서 재확인한다.
보호자가 화면을 보지 않아도 재확인 중임을 알 수 있도록 안내음을 재생한다. 작업이 실패해 멈추면 그 원인을 음성으로 알린다.

### 1단계: 장난감 확보 (미보유 시)

카메라 영상에서 지정된 낚시 장난감을 인식하고 위치와 방향을 추정한다.
로봇팔이 도달할 수 있는 위치로 접근한 뒤 집게로 잡아 들어 올린다.
초기 인식 대상은 차터에 따라 손잡이에 색상 표식이 있는 장난감으로 한다.

### 2단계: 고양이 접근

회차에서 처음 전용 장난감 보유가 확인된 순간 놀이 타이머와 고양이 탐색을 함께 시작한다. 새로 집어 든 경우에는 파지 성공을 확인한 시각부터 센다.
고양이가 아직 보이지 않으면 제한된 탐색 이동을 수행하고, 발견하면 카메라로 위치와 거리를 추정한다.
장난감을 잡은 상태로 고양이에게 접근하며 위치와 거리를 갱신한다.
설정한 전환 거리에 도달하면 3단계로 전환한다. 전환 거리의 수치는 추후 결정한다.

### 3단계: 고양이에게서 멀어지기

카메라로 고양이의 위치와 거리를 갱신하면서 고양이와의 거리가 증가하도록 이동한다.
동시에 로봇팔은 장난감을 잡은 채 좌우로 흔들거나 집게 끝으로 원을 한 바퀴 그린다. 실행할 동작은 지정된 패턴 중 무작위로 선택한다.
여기서 '점점 멀어진다'는 거리 증가를 뜻하며, 속도를 점점 높이는 동작은 포함하지 않는다.
외출 모드에서는 장난감 보유 확인부터 10분이 지나면 회차를 종료한다. 바로 놀이의 회당 시간은 추후 결정한다.

### 이동 중 장애물 회피

이동 방향에 장애물이 감지되면 정지한다.
회전이 가능한 경우 좌·우 중 무작위 방향으로 90도 회전하고 전방을 다시 확인한다.
여전히 막혀 있으면 회피 절차를 반복하고, 설정한 최대 시도 횟수에 도달하면
정지 상태를 유지하고 회피 실패를 알린다.
회전 중에도 몸체, 로봇팔 및 장난감의 충돌 가능성을 확인해야 한다.

## 4. 검증할 핵심 질문

- 카메라 영상으로 장난감의 접근·파지에 필요한 위치와 방향을 추정할 수 있는가?
- 추정 결과를 이용해 이동부와 로봇팔을 연동하여 장난감을 집어 들 수 있는가?
- 카메라로 고양이의 위치와 거리를 추정하고 접근·멀어지기 단계를 전환할 수 있는가?
- 랜덤 90도 회전 후 장애물을 재확인하고 동작을 재개하거나 실패 상태로 종료할 수 있는가?
- 인식 실패, 파지 실패 및 정지 명령에 일관되게 대응할 수 있는가?

## 5. 검증 한계

시뮬레이션 결과만으로 실제 고양이의 흥미나 놀이 효과를 확정하지 않는다.
실제 환경의 인식·파지 성능과 낚싯줄 얽힘을 포함한 실물 안전성은 후속 검증 대상이다.
