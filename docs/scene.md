# D07 장면 XML 실행 안내 — 단순 팔·낮은 본체·장난감 통

장면 사양은 [시스템 설계의 구성표](system-design.md#모델과-장면-구성표--d07)를 기준으로 한다.
진입 파일은 [scenes/fishingbot.xml](../scenes/fishingbot.xml)이고,
[scenes/tidybot_robot.xml](../scenes/tidybot_robot.xml)을 포함한다. 로봇 메시 파일도 함께 필요하다.

## 설치와 실행

프로젝트 루트에서 실행한다. 이미 설치된 `.venv`는 그대로 사용할 수 있다.

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements-sim.txt
.venv\Scripts\python.exe scripts\fetch_tidybot.py
.venv\Scripts\python.exe scripts\build_scene.py
.venv\Scripts\python.exe scripts\scene.py
.venv\Scripts\python.exe scripts\scene.py --view
```

`scene.py`는 `home` 키프레임으로 초기화하고 커스텀 팔과 본체의 위치 제어 목표를 유지한다.
옵션 없이 실행하면 장면 검사·렌더링을, `--view`이면 대화형 뷰어를 실행한다.
네이티브 MuJoCo 뷰어에서 XML을 직접 열 때는 `home` 키프레임을 적용한 뒤 재생한다.
기본 영 관절 자세로 재생한 결과는 준비된 시작 자세의 시험 결과와 다르다.

공식 모델 원본은 `models/stanford_tidybot/tidybot.xml`에 보존한다.
`build_scene.py`는 TidyBot 본체 메시의 높이를 시각·충돌 형상 모두 50%로 축소하고 팔을 커스텀 4관절 구조로 교체한다.
팔·집게 구조는 `scripts/simple_arm.py`에서 관리한다. 팔 4축과 집게 개폐 1개 명령을 사용하며,
집게의 양쪽 슬라이드 관절은 동일하게 움직이도록 결합한다.
원본 팔·집게는 최종 장면에 포함하지 않는다. 본체 질량 설정은 유지하고 관성은 축소된 메시로 다시 계산한다.
팔의 관절 범위·힘·질량은 시뮬레이션용 초기값으로, 원본 TidyBot의 물리 제원이 아니다.
다운로드 버전과 SHA-256은 `models/tidybot-source.json`, 라이선스는 `models`의 각 모델 폴더에 있다.
약 8MB의 원본 메시 자산은 Git에서 제외하며, 새 환경에서는 다운로드 스크립트를 먼저 실행한다.

## 임시 배치와 센서

아래 값은 모델링을 위한 임시 배치이며 집기 도달성 검증으로 확정한 값이 아니다.

| 항목 | 장면 값 |
| --- | --- |
| 좌표계 | world, z 상방, 거리 m |
| 로봇 시작 | 본체 (0, 0, 0), 커스텀 home 팔 자세, 빈 집게 |
| 본체 | 가로·세로는 유지, 메시 높이는 원본의 50%. 팔 장착 높이 0.16m |
| 장난감 통 | 중심 (0.75, 0, 0)m, 높이 0.26m, 외경 0.15m. 바닥과 벽 24개로 구성한 열린 통 |
| 내부 가이드 | 통 안에서 가는 막대를 세워 지지하는 수동 가이드. 아래에 줄이 빠져나갈 틈을 둠 |
| 손잡이 중심 | (0.75, 0, 0.29)m, 가는 막대는 아래로 향함. 위쪽 약 8cm가 통 밖으로 노출 |
| 카메라 base | 짧은 지지대 위 본체 기준 (0.28, 0, 0.24)m, 앞쪽 위로 관측, 수직 시야각 60°, 640 × 480 |
| 질량 배분 | 손잡이 45g + 가는 막대 25g + 줄 10g + 공 20g |

`base` 카메라를 RGB·깊이 렌더링에 사용할 수 있다. 기존 팔의 `wrist` 카메라는 교체한 팔에 포함하지 않는다.
손잡이 중앙의 초록 띠는 질량·충돌 없는 시각 표식이다.
`left_grip_force`·`right_grip_force`는 양쪽 집게 손가락 영역의 접촉 힘(N)을 제공한다.
접촉 힘만으로 장난감 파지를 판정하지 않으며, 실제 파지 제어에서는 접촉 상대도 확인해야 한다.
`handle_world`·`toy_world`는 평가용 실제 좌표(m)로, 카메라 인식 결과가 아니다.

## 장면 검사와 한계

`scene.py`는 물체 치수·질량 합·독립 물체 여부를 검사한 뒤, 고정 제어 목표로 3초간 물리 시뮬레이션한다.
낚싯대의 통 내부 유지, 표식 노출, 공이 통 안에 있는지, 팔 4축 구성, 수치 안정성,
낚싯대 접촉의 관통 깊이, 초록 표식의 카메라 가시성을 확인한다.
결과는 `output/scene/check.json`과 같은 폴더의 전체 장면·RGB·깊이 이미지로 저장한다.
`base_depth_m.npy`는 미터 단위 원본 깊이이고 `base_depth.png`는 시각화이다.

- 줄은 2cm 강체 링크 10개와 볼 관절로 만든 근사 모델이다. 실제 줄의 탄성·매듭·얽힘을 재현하거나 보증하지 않는다.
- 낚싯대에는 자유 관절이 있고 로봇에 강제 고정하지 않는다. 현재는 통 안의 가이드에 세운 상태이며 줄·공은 통 내부에 있다.
- 파란 작업 경계는 시각 표시이며 충돌벽이 아니다. 범위 제한은 이후 Safety 제어에서 구현해야 한다.
- 위치 인식·접근·파지·흔들기 제어와 집게의 도달성은 아직 검증하지 않았다.
- 정상 장면에는 고양이와 추가 장애물을 넣지 않았다. 이들을 사용하는 안전 시험은 후속 단계이다.
