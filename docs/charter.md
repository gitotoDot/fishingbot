# FishingBot 🐱🎣

고양이 놀이 로봇 프로젝트 팀 차터

## 목표

로봇청소기처럼 실내를 이동하고, 카메라로 고양이 낚시 장난감을 인식해 로봇팔 끝의 집게로 잡아 움직이며, 고양이 근처로 다가가 낚시 장난감으로 고양이랑 놀아준다.

## 범위

### 한다 (In)

- 이동부와 상단 로봇팔을 갖춘 시제품 설계·개발
- AI를 활용해서 카메라로 지정된 고양이 장난감을 찾는다.
- 이동부 카메라로 장난감의 위치와 방향 인식
- 장난감 근처로 이동해 집게로 정렬하고 잡는 기능 구현
- 원격 조작을 통한 기본 동작 확인
- 속도·집게 힘 제한, 장애물 감지 등 기본 안전 기능 적용

### 안 한다 (Out)

- 고양이의 감정이나 행동을 완전히 이해하는 고도화된 AI
- 낚싯줄이 고양이에게 감기거나 끼이지 않는다는 안전성의 완전한 보증
- 24시간 작동하지 않는다.

## 플랫폼 결정

- **하드웨어:** 로봇청소기 형태의 차동 구동 이동부, 상단 로봇팔, 끝단 집게
- **인식:** 이동부 카메라로 장난감을 탐지하고 위치를 추정
- **초기 시제품:** 장난감 손잡이에 색상 표식을 달아 인식 성능을 높임
- **운용:** 원격 조작부터 시작하고, 확인된 기능을 순차적으로 자동화

- **매일 스크럼:** 매일 짧게 진행 상황, 오늘 할 일, 막힌 점을 공유한다.
