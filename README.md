# FishingBot 🐱🎣

구동 기능과 로봇팔을 활용해 고양이와 놀아주는 낚시 장난감 봇입니다.
구동부와 로봇팔을 연동해 낚시 장난감을 다양한 패턴으로 움직이며,
고양이의 호기심과 사냥 본능을 자극하는 것을 목표로 합니다.

## 개발 상태

초기 개발 단계입니다.
Stanford TidyBot 기반의 낮은 본체·단순 4관절 팔·장난감 통을 갖춘 MuJoCo 장면 XML을 구성했습니다.
실행 방법과 장면 검사는 [D07 장면 실행 안내](docs/scene.md)를 참고하세요.

## 개발 계획

- 소프트웨어 요구사항 및 제어 구조 설계
- 구동부와 로봇팔의 동작 모델 정의
- 낚시 장난감의 움직임과 놀이 패턴 제어 로직 구현
- MuJoCo에서 구동부와 로봇팔을 연동한 시뮬레이션 환경 구성
- 시뮬레이션에서 움직임 패턴, 작동 범위 및 정지 동작 검증
