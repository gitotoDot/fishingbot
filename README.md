# FishingBot 🐱🎣

구동 기능과 로봇팔을 활용해 고양이와 놀아주는 낚시 장난감 봇입니다.
구동부와 로봇팔을 연동해 낚시 장난감을 다양한 패턴으로 움직이며,
고양이의 호기심과 사냥 본능을 자극하는 것을 목표로 합니다.

## 개발 상태

초기 개발 단계입니다.
하드웨어 구성과 실행 방법은 개발 진행에 따라 추가합니다.

## 개발 계획

- 구동부와 로봇팔의 하드웨어 구성 및 제어 방식 설계
- 구동부와 로봇팔을 연동한 낚시 장난감 움직임 구현
- 다양한 놀이 패턴 구현
- 놀이 시간과 휴식 간격 설정
- 안전한 작동 범위와 정지 기능 구현
